### User Stories Overview

#### Admin User Stories
- **Title:** Manage Doctor Accounts
  - **As an** Admin,
  - **I want to** add, edit, and deactivate doctor profiles in the system,
  - **So that** clinic scheduling and staff records remain up to date.

#### Doctor User Stories
- **Title:** View Scheduled Appointments
  - **As a** Doctor,
  - **I want to** retrieve my daily and weekly appointment calendar,
  - **So that** I can prepare for patient consultations in advance.

#### Patient User Stories
- **Title:** Search Doctors and Book Appointments
  - **As a** Patient,
  - **I want to** filter doctors by specialty/availability and book a time slot,
  - **So that** I can receive timely medical care without clinic delays.
